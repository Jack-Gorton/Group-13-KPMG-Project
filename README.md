# Problem Statement
Wasatch Outfitters Collective is currently focusing on the challenge of how WOC can better market its products and connect with its target customers. The problem is not only getting people to know that WOC exists, but figuring out how WOC can communicate its value om a way that reaches the right customers. Our team will recommend a practical technology solution that WOC can implement within six to twelve months.

# Proposed Solution

WOC should develop a more targeted marketing strategy focused on its ideal customer segments in order to increase brand awareness, strengthen customer engagement, and drive sales.


## Repository Contents

### Milestone 1: Brand Strategy and Social Media Analytics

This lab compares Doritos and Pringles Super Bowl advertising campaigns using social media engagement data. We used Excel to calculate descriptive statistics, correlations, and regression results and to create charts showing engagement patterns across platforms. We also used ChatGPT through multiple prompts to interpret the data, challenge conclusions, and develop marketing recommendations. The final report compares Excel’s reliable quantitative analysis with ChatGPT’s ability to explain results and generate business insights, then recommends the stronger campaign and improvements for future social media strategy.

### Milestone 2: Tableau BI Data Visualization

This lab used Tableau to turn marketing data into visualizations and a professional dashboard. We analyzed ad spend, revenue, customer acquisition cost, and conversions across marketing channels to identify which channels performed best. The project showed how dashboards can help marketing teams quickly find trends and support data-driven campaign recommendations.

### Milestone 3: Mobile App Using Thunkable

In this lab we used Thunkable to build a mobile marketing app without coding. We created a campaign performance summary tool that lets marketing managers view a channel’s ad spend, conversions, and customer acquisition cost. The app demonstrated how a unified dashboard could replace manual marketing data tracking.

### Milestone 4: AI-Assisted Database Investigation – Solving the SQL Murder Mystery

This lab investigated a fictional crime using a relational database and AI-generated SQL queries. We used the database diagram to locate evidence, verify query results, and refine prompts when needed. The project showed how AI can support database analysis while human judgment is still needed to confirm accurate conclusions.

### Milestone 5: Creating a Virtual Machine in Google Cloud

This lab used Google Cloud to create virtual machines and host a basic NGINX web server. We compared cloud deployment through the console and command line while considering cost, reliability, and scalability. The project showed how startups can use cloud infrastructure to launch services quickly without buying physical servers.

### Milestone 6: IS Collaboration with Google Drive & Gemini AI (Group Work)

This group project designed an import business and the information systems needed to support it. We researched the market, competitors, pricing, supply chain, and sales options while using Gemini to organize insights and verify key findings. The project showed how AI, shared cloud tools, and human judgment can work together to guide a business launch decision.
